💾 Backup e Restauração de Dados

📌 Importante!

Os dados são salvos apenas no navegador deste computador. Use estas funções para fazer backup e transferir dados entre computadores.

📥 Exportar Dados (Fazer Backup)

Baixe um arquivo com todos os seus dados cadastrados.

Arquivo incluirá: Procedimentos, Atalhos, Logos e Perguntas Pendentes

📤 Importar Dados (Restaurar Backup)

Carregue um arquivo de backup anterior para restaurar todos os dados.

⚠️ Atenção: Isso substituirá todos os dados atuais!

🗑️ Limpar Todos os Dados

Remove todos os dados do sistema. Esta ação é irreversível!

⚠️ CUIDADO: Faça backup antes de limpar!
